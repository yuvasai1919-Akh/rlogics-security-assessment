# Evidence

Everything under `evidence/runs/` and the OpenBao/K8s outputs is **generated by your own runs**.
Replace nothing here with someone else's output - the interview will ask you to explain it.

| Source | Command | Output location |
|--------|---------|-----------------|
| DevSecOps (vulnerable) | `make pipeline-vuln` | `evidence/runs/<timestamp>-vulnerable/` |
| DevSecOps (remediated) | `make pipeline-fixed` | `evidence/runs/<timestamp>-remediated/` |
| OpenBao PKI | `make openbao-pki` | `evidence/openbao/pki-<timestamp>/` |
| OpenBao DB | `make openbao-db` | `evidence/openbao/db-<timestamp>/` |
| K8s admission demo | `make k8s-demo` | `evidence/k8s/admission-demo.txt` |
| K8s NetworkPolicy test | `make k8s-netpol` | `evidence/k8s/networkpolicy-test.txt` |
| K8s scans | `make k8s-scan` | `evidence/k8s/trivy-k8s-*.{json,txt}` |
| Scan gate script | `make test-gate` | terminal output (paste into `curated/`) |

## Curate before committing
Raw runs are gitignored (`evidence/runs/`). Copy the **representative** files into `evidence/curated/`
(Semgrep, Trivy, SBOM, ZAP, Cosign, gate summaries, cert inspection, lease output, scanner diffs) and
commit only those. Check each file for secrets or personal data first. Add a short
`evidence/curated/NOTES.md` saying what each file shows and what you learned.

## Also record (`evidence/environment.txt`)
OS and host, Docker/Rancher version, `kubectl version`, kind version, Kyverno chart/app version,
tool image tags/digests actually used, and anything that behaved differently from the docs.
